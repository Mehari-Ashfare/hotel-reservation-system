HOTEL RESERVATION SYSTEM API
============================

Local base URL: http://localhost:5000/api
Interactive reference: http://localhost:5000/api-docs
Full endpoint details: API_DOCUMENTATION.md

ROUTE GROUPS
------------
Authentication: POST /auth/register, /auth/login, /auth/forgot-password,
                /auth/reset-password, /auth/refresh, /auth/logout,
                /auth/change-password; GET and PUT /auth/profile; GET /auth/me
Guests:         /guests
Rooms:          /rooms
Reservations:   /reservations
Payments:       /payments
Reports:        /reports
Staff:          /staff
Audit:          /audit (admin only)
Dashboard:      /dashboard

SYSTEM ROUTES
-------------
GET /health
GET /metrics
GET /system/info
GET /system/staff-status

AUTHENTICATION
--------------
For protected routes, send:
Authorization: Bearer <JWT token>

Use the route files in backend/src/routes/ and the full API reference for
current methods, paths, and role requirements.
