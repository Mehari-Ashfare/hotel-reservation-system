# Frontend - Hotel Reservation System

## Purpose
This directory contains the client-side React application. It interacts with the Express backend API to manage guests, rooms, and reservations.

## Tech Stack
- **Build Tool:** Vite
- **Framework:** React 18
- **UI Library:** Material UI (MUI) v5
- **Routing:** React Router DOM v6
- **HTTP Client:** Axios
- **State Management:** React Query (@tanstack/react-query)

## Usage
1. Run `npm install`
2. Run `npm run dev` to start the development server.
